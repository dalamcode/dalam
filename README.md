# Dalam

A local-first BYOK (Bring Your Own Key) AI coding tool.

## Features

- **Desktop App** - Electron app for macOS, Windows, Linux
- **CLI/TUI** - Terminal-based interface
- **VS Code Extension** - Editor integration
- **Web App** - Browser-based UI
- **15+ LLM Providers** - OpenAI, Anthropic, Google, Azure, Bedrock, and more
- **Plugin System** - Extend with custom tools
- **Theme System** - Customizable UI themes

## Installation

### Desktop App
Download from [Releases](https://github.com/ajmaluk/dalam/releases)

### CLI
```bash
npm install -g dalam
```

### VS Code Extension
Search for "Dalam" in the VS Code Marketplace.

## Usage

1. Install Dalam
2. Add your API keys (OpenAI, Anthropic, etc.)
3. Start coding with AI assistance
